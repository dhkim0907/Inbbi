# Inbbi

Android, iOS, 웹을 지원하는 Flutter 애플리케이션입니다.

개발 지침은 [AGENTS.md](AGENTS.md), AI와 함께 작업하는 절차와 검증 기준은 [하네스 엔지니어링](docs/harness_engineering.md)을 참고합니다.

```sh
flutter pub get
bash tool/verify.sh
```

여러 단계의 작업은 [작업 템플릿](docs/tasks/TEMPLATE.md)에 범위, 완료 조건, 검증 결과를 기록합니다. 기능별 연결 설정과 검증 방법은 `docs/`에 있습니다.
