# 작업: 프로젝트 중간 발표 PPT

상태: 완료

## 목표와 범위

- 수업 발표 7~10분용 한국어 PPTX와 슬라이드별 발표자 노트를 작성한다.
- 현재 코드와 README를 근거로 구현 현황, 검증 결과, 후속 계획을 구분한다.
- 기존 앱 UI와 Dart 코드는 변경하지 않는다.
- 기존 위젯 테스트의 모바일·데스크톱 화면 캡처를 사용한다. 데이터는 테스트 데이터다.

| 명령 또는 재현 절차 | 환경 | 실제 결과 |
|---|---|---|
| `bash tool/verify.sh` | 현재 저장소 | 기존 강의 화면의 서식 차이로 첫 단계 종료. 자동 수정 없음 |
| `flutter analyze --no-pub` | 현재 저장소 | No issues found |
| `INBBI_UI_REVIEW=1 flutter test --no-pub --reporter expanded` | 모의 서비스·테스트 데이터 | 163개 통과, 10개 실패. 캘린더 서버 연결 복원·Google 설정 관련 실패 포함 |
| 실제 계정·기기 전달 | 외부 환경 | 미실행. 발표에서 별도 검증 대상으로 표시 |
