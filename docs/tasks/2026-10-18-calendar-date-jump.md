# 작업: 캘린더 날짜 선택으로 이동

상태: 완료

## 목표와 범위

- 월 선택 버튼을 첨부 이미지의 날짜 입력 팝업으로 변경한다.
- 날짜 입력, 달력 선택, 오늘 입력, 이동을 제공한다.
- 기존 날짜 선택 대화상자와 CalendarDesign 색상을 재사용한다.
- 다른 화면·캘린더 UI와 기존 사용자 변경, 삭제된 문서는 보존한다.
- 외부 서비스·의존성 변경은 없다.

## 완료 조건

- [x] 버튼 아래에서 날짜를 입력하고 해당 월·날짜로 이동한다.
- [x] 오늘 입력, 달력 선택, 바깥 클릭으로 닫기가 동작한다.
- [x] 존재하지 않는 날짜를 거부하고 윤년 2월 29일을 허용한다.
- [x] 모바일·데스크톱 및 839/840 경계 테스트와 캡처 확인
- [x] 수정 파일 서식·정적 분석·관련 테스트 통과 및 전체 검증 결과 기록

## 남은 사항

- 실제 브라우저·기기의 가상 키보드 동작은 미검증이다.
- 전체 실패 10개는 서버 연결 복원 1개, 보류 푸시 클릭 1개, 외부 알림 설정 3개, Google 설정 연결 행 2개, 서버 연결 버튼 2개, Google 일정 권한 요청 1개다. 요청 범위 밖이므로 수정하지 않았다.
- 날짜 선택 범위는 기존 선택창과 동일하게 2000~2100년이다. ‘오늘’은 입력값만 변경하고 ‘이동’으로 적용한다.
